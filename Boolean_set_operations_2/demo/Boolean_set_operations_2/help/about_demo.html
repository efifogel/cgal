This program demonstrates the operations on general polygons offered by the 2D Regularized Boolean Set-Operations and the 2D Minkowski Sums packages of CGAL.

  • You construct general polygons with holes bounded by curves of one family at a time: line segments, line segments and circular arcs, conic arcs, Bezier curves, algebraic curves (if the demo is built with Lexy), or polylines. Switching to another family discards the polygons.
  • The polygons are kept in buckets. A bucket holds a set of interior-disjoint polygons, drawn in the color of the bucket. The program starts with three buckets; you can add buckets up to seven, and drag the rows of the Operations panel to reorder them.
  • The operations apply to entire buckets: complement, intersection, union, difference, symmetric difference, and Minkowski sum (line segments only). Copy, Move, and Clear transfer or remove the polygons of buckets.
  • The polygons you construct or open, and the results of the operations, are added to the Draw/Insert bucket.
  • You can save the polygons of the Draw/Insert bucket in a file and open saved files.
  • Undo goes back one step at a time; Reset starts over.
  • The log holds the program: the Python statements that reproduce the buckets. You can also type statements in the console. Save Program writes the program as a Python script, which runs with the Python bindings of CGAL.

To learn what a button or a panel does, press the What's This button (or Shift+F1) and click it.
